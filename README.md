> Расширение для Firefox, которое отслеживает цены на **Ozon**, **Wildberries**, **Яндекс.Маркет** и **AliExpress** с историей, графиками, сравнением цен и уведомлениями.

---

## ✨ Возможности

- 💰 **Текущая цена** — в виджете на странице товара
- 🔴 **Старая цена и скидка** — автоматический расчёт
- 📈 **История цен** — до 500 записей на товар
- 📊 **График динамики** — Canvas с мин/макс/последней ценой
- 🔔 **Уведомления** — при падении/росте цены (настраиваемый порог)
- 🏆 **Минимальная цена** — уведомление при достижении
- 🔍 **Сравнение цен** — поиск на других маркетплейсах в один клик
- 📁 **Категории (60)** — с автоопределением по названию
- 🔎 **Поиск и фильтры** — по названию, тегам, категориям
- 💾 **Экспорт/импорт** — CSV (Excel), JSON (бэкап)
- 🔄 **Массовое обновление** — кнопка «Обновить» в попапе
- ♻️ **Резервное копирование** — `pt_tracked_backup`
- 🌍 **Валюты** — ₽, $, €, ¥, ₸, Br и ещё 25+
- ⚙️ **Страница настроек** — общие, уведомления, хранилище

## 🚀 Установка

### Из AMO (рекомендуется)

1. Откройте [страницу расширения на AMO](https://addons.mozilla.org/ru/firefox/addon/price-tracker-ozon-wb-yandex/)
2. Нажмите **«Добавить в Firefox»**
3. Готово
