# Changelog

Все значимые изменения в проекте **Price Tracker — Ozon, WB, Яндекс.Маркет, AliExpress**
документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
версионирование — по [Semantic Versioning](https://semver.org/lang/ru/).

## [3.2.0] — 2026-10-16

### Added
- Расширен список категорий: 40 → 60
- Новые группы категорий:
  - Медицина: Аптека, Медтехника, Оптика
  - Быт: Бытовая химия, Гигиена, Уборка
  - Стройка: Стройматериалы, Электрика, Сантехника
  - Активный отдых: Рыбалка, Охота, Туризм, Зимний спорт, Водный спорт
  - Умный дом: Умный дом, Безопасность
  - Дети: Детское питание, Школа
  - Творчество: Творчество, Музыкальные инструменты
- Правила `suggestCategory` для 20 новых категорий —
  товары автоматически определяются

### Changed
- Версия: 3.2.0

## [3.1.0.4] — 2026-10-09

### Added
- Определение пользователя из Казахстана по часовому поясу
  (`isKzUser()` — проверка `Intl.DateTimeFormat().resolvedOptions().timeZone`)
- Казахстанцы теперь видят `Ozon KZ` во всех менюшках
  «🔍 Найти на других» (на WB, Яндексе, Ali)
- Предупреждение для казахстанцев при переходе на `Ozon RU`:
  доставка не всех товаров, оплата только картой КЗ, срок 10–20 дней

### Fixed
- **Wildberries**: цена не определялась на части товаров —
  расширены селекторы + fallback-сканирование DOM
- **Сравнение цен**: `Ozon KZ` больше не показывается россиянам
  (определяется по часовому поясу)

### Changed
- Версия: 3.1.0.4
- `core.js`: добавлена функция `isKzUser()`
- `core.js`: фильтр `otherMarkets` учитывает `kzUser`

## [3.1.0.3] — 2026-10-09

### Fixed
- Исправлена проблема с определением MARKET: `core.js` больше не устанавливает
  `window.MARKET = 'unknown'` — он ждёт, пока модуль площадки установит его
- `ozon.kz` теперь корректно определяет `MARKET = 'ozon_kz'`

### Changed
- `core.js`: `init()` ждёт `window.MARKET` до 2 секунд (20 попыток × 100мс)
- `core.js`: `getSearchUrl` и `allMarkets` включают `ozon_kz`
- Версия: 3.1.0.3

### Note
- Тестовая версия для проверки ozon.kz

## [3.1.0.2] — 2026-10-08

### Added
- Поддержка `ozon.kz` (Казахстан) — тестовая версия
- Определение домена Ozon (RU/KZ) через `window.location.hostname`
- Валюта `KZT` (₸) для казахстанской витрины
- Разделение товаров Ozon RU и Ozon KZ в хранилище (`ozon` / `ozon_kz`)
- Метка «Ozon KZ» в виджете и попапе

### Changed
- `manifest.json`: добавлены домены `ozon.kz` в `matches` и `permissions`
- `ozon.js`: поддержка символа `₸` при парсинге цен
- Версия: 3.1.0.2 (тестовая)

### Note
- Это тестовая версия. Селекторы цен на `ozon.kz` могут отличаться —
  нужна проверка от пользователя из Казахстана.
- `ozon.ru` работает без изменений.

## [3.0.7.1 — 2026-10-06

## [3.0.7] — 2026-09-16

### Added
- Поддержка AliExpress (`aliexpress.com`, `aliexpress.ru`)
- Определение ID, названия, цены и скидки для AliExpress
- `retryGetPrices` для AliExpress (10 попыток × 700мс) — цена появляется
  с задержкой после загрузки React-компонентов
- Поддержка валют: `₽`, `$`, `€`, `¥`, `₸`, `Br` и ещё 25+ символов
- Функция `getCurrencySymbol(code)` — код валюты → символ
- Валюта сохраняется в `pt_tracked` (`currency: 'RUB'`)
- Символ валюты отображается в виджете, попапе, CSV и уведомлениях
- Кнопка «🔍 Найти на других» — открывает менюшку с маркетплейсами
  (кроме текущего) для поиска товара по названию

### Fixed
- AliExpress: цена берётся из DOM (классы `HazeProductPrice_SnowPrice__*`),
  так как `window.data.products[0].price` всегда равен 0
- AliExpress: fallback-сканирование DOM на символ ₽
- Уведомления и CSV больше не пишут `₽` жёстко
- AliExpress: `retryGetPrices(10, 700)` — цена появляется с задержкой

### Changed
- `manifest.json`: название включает AliExpress
- `manifest.json`: добавлены разрешения и content script для AliExpress
- `formatPrice(price, currency)` — второй параметр — код валюты
- `checkNotifications` принимает `currency`
- `exportToCSV` и `saveToFile` принимают `currency`
- В попапе статистика показывает символ только если все товары в одной валюте

## [3.0.6] — 2026-09-12

### Added
- Переход к товару по клику на карточку в списке отслеживаемых
- Fallback-генерация ссылки для старых записей без сохранённого `url`:
  - Ozon → `https://www.ozon.ru/product/{id}/`
  - Wildberries → `https://www.wildberries.ru/catalog/{id}/detail.aspx`
  - Яндекс.Маркет → `https://market.yandex.ru/product/{id}`
- Функция `escapeHtml()` для безопасного рендера данных в попапе (защита от XSS)
- Подсказка (`title`) при наведении на карточку товара

### Changed
- Карточки товара стали кликабельными (`cursor: pointer`, hover-эффект)
- Кнопка удаления (`✕`) теперь не срабатывает при клике по карточке (`stopPropagation`)

### Fixed
- Не открывалась страница товара при клике на элемент списка в попапе

## 📋 Типы изменений

- `Added` — новая функциональность
- `Changed` — изменения в существующей функциональности
- `Deprecated` — функции, которые скоро будут удалены
- `Removed` — удалённая функциональность
- `Fixed` — исправления багов
- `Security` — исправления уязвимостей
